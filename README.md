# Silver Workstation

My personal Linux workstation environment.

A collection of configurations, scripts and tools used to maintain a consistent Linux desktop experience across different distributions.

## Environment

- KDE Plasma
- Kitty
- Zsh
- Starship
- Fastfetch

## Visual Identity

A metallic silver and steel-blue color palette.

## Supported distributions

- Fedora Linux
- Debian GNU/Linux

## Structure

- `kitty/` — Terminal configuration
- `shell/` — Zsh and Starship configuration
- `fastfetch/` — System information display
- `wallpapers/` — Desktop wallpapers
- `screenshots/` — Desktop previews
- `packages/` — Distribution-specific installation scripts
